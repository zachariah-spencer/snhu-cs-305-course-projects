# Artemis Financial Software Security Vulnerability Assessment & Report
### Southern New Hampshire University - Computer Science 305 - Course Final Projects
&nbsp;


## Briefly summarize your client, Artemis Financial, and its software requirements. Who was the client? What issue did the company want you to address?
Artemis Financial is a financial services company that approached me for assistance in enhancing their software security by addressing vulnerabilities within their existing online system.
&nbsp; 

## What did you do well when you found your client’s software security vulnerabilities? Why is it important to code securely? What value does software security add to a company’s overall well-being?
After identifying specific software security gaps, I successfully patched these vulnerabilities, reinforcing the system’s defenses. I felt my technical writing was a highlight during this process and allowed me to effectively communicate the business value of the vulnerability assessment process. Secure coding is essential as it safeguards sensitive data from unauthorized access and mitigates the risk of data breaches. Strong software security enhances a company’s reputation, upholds customer trust, and reduces the financial impact of potential breaches.
&nbsp; 

## Which part of the vulnerability assessment was challenging or helpful to you?
The vulnerability assessment, though challenging, was invaluable in pinpointing weaknesses in the system. This process required a thorough understanding of the system architecture and potential security threats.
&nbsp;

## How did you increase layers of security? In the future, what would you use to assess vulnerabilities and decide which mitigation techniques to use?
To strengthen the security layers, I implemented multi-factor authentication, encrypted sensitive data, and set up a firewall. Going forward, I would incorporate vulnerability scanning tools and conduct penetration testing to identify vulnerabilities and determine appropriate mitigation measures.
&nbsp;

## How did you make certain the code and software application were functional and secure? After refactoring the code, how did you check to see whether you introduced new vulnerabilities?
To ensure the application remained both functional and secure, I carried out rigorous testing and code reviews. Following code refactoring, I used static code analysis tools to verify that no new vulnerabilities had been introduced.
&nbsp;

## What resources, tools, or coding practices did you use that might be helpful in future assignments or tasks?
In this project, the use of vulnerability scanning tools, penetration testing, and secure coding practices proved particularly effective, and I look forward to leveraging these resources in future tasks.
&nbsp;

## Employers sometimes ask for examples of work that you have successfully completed to show your skills, knowledge, and experience. What might you show future employers from this assignment?
As a demonstration of my work, I could present future employers with the secure code developed for Artemis Financial, the vulnerability assessment report, and the mitigation steps I implemented. This would showcase my expertise in software security and my practical experience in addressing security challenges."
